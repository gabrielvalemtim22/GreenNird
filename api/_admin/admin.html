Como conectar o WhatsApp (API oficial da Meta)

  1. Entre em developers.facebook.com → Meus apps → Criar app → tipo Empresa → adicione o produto WhatsApp.
  2. Em WhatsApp → Configuração da API, copie o Phone number ID e gere um token de acesso permanente (Usuário do sistema no Gerenciador de Negócios).
  3. Em Configurações do app → Básico, copie a Chave secreta do app (App secret).
  4. Na Vercel (projeto greennird → Settings → Environment Variables), crie: WHATSAPP_TOKEN, WHATSAPP_PHONE_ID, WHATSAPP_APP_SECRET e WHATSAPP_VERIFY_TOKEN (uma senha que você inventa). Depois faça Redeploy.
  5. Em WhatsApp → Configuração → Webhook, cole a URL do webhook abaixo e a mesma senha do WHATSAPP_VERIFY_TOKEN. Clique em verificar e assine o campo messages.
  6. Pronto: mande uma mensagem para o número e o Grok responde sozinho. ✅
Opcional: WHATSAPP_PROMPT define como o robô atende (ex.: “Você é atendente da loja X, vende Y, horário Z…”).
